\# AI Resume Analyzer

A Java Spring Boot application for AI-powered resume analysis.

## Features
- Skill detection and scoring
- REST API at /api/v1/resume/analyze
- Accepts plain text .txt resume files
- Docker support
- Unit tests included

## Run
cmd: mvnw.cmd spring-boot:run

App runs at http://localhost:8080
