# \# AI Resume Analyzer

# 

# A Java Spring Boot REST API that analyzes resumes and generates skill match scores.

# 

# \## Tech Stack

# \- Java 17

# \- Spring Boot 3.2.4

# \- Maven

# \- Docker

# \- JUnit 5

# \- GitHub Actions CI/CD

# 

# \## How to Run

# 

# \### Prerequisites

# \- Java 17+

# \- Git

# 

# \### Steps

# git clone https://github.com/kritikaghosh45/ai-resume-analyzer.git

# cd ai-resume-analyzer

# mvnw.cmd spring-boot:run

# 

# App runs at http://localhost:8080

# 

# \## API Usage

# 

# POST http://localhost:8080/api/v1/resume/analyze

# 

# Body (form-data):

# \- file: your resume (.txt)

# \- jobTitle: Java Developer

# 

# \## Features

# \- Resume text extraction

# \- Skill detection and matching

# \- JSON score response

# \- Docker support

# \- Unit tested

##### \- CI/CD pipeline
